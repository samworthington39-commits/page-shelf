# 页架 Page Shelf v1.0.9

**NAS 图书管理器 / NAS Library Manager**

这是一个存储授权兼容性修复版本。页架管理用户自己拥有或有权使用的本地 TXT、EPUB、PDF 文件；
本项目及本 Release 不包含或分发任何图书资源。

This patch release fixes storage authorization compatibility. Page Shelf manages local TXT, EPUB, and PDF files
that users own or are authorized to use. Neither the project nor this release contains or distributes book content.

## 修复 / Fixes

- 修复 `/library:ro` 或 NAS 只读挂载被错误要求写权限，导致后台提示容器存储授权异常的问题。
- 保留目录读取、目录进入、授权根边界及符号链接越界检查。
- 书库仍可按推荐配置保持只读，容器无需获得原始图书文件的写权限。

## 下载 / Downloads

- `page-shelf-v1.0.9-arm64.apk`: Android 8.0+，仅支持 `arm64-v8a`。
- `page-shelf-v1.0.9-docker.zip`: Docker Compose 后端部署包。
- `SHA256SUMS.txt`: APK 和部署包的 SHA-256 校验值。

## Docker

镜像支持 `linux/amd64` 和 `linux/arm64`：

```bash
docker pull ghcr.io/samworthington39-commits/page-shelf:v1.0.9
```

也可以使用滚动更新标签：

```bash
docker pull ghcr.io/samworthington39-commits/page-shelf:latest
```

更新已有部署：

```bash
docker compose pull
docker compose up -d --force-recreate
```
