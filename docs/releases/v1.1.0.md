# 页架 Page Shelf v1.1.0

**NAS 图书管理器 / NAS Library Manager**

本版本增加 MOBI 与浏览器阅读，并将 Android 朗读切换为完全端侧的
sherpa-onnx + Matcha-TTS 方案。页架只管理用户自己拥有或有权使用的本地图书文件；本项目及
本 Release 不包含或分发任何图书资源。

This release adds MOBI and browser reading, and moves Android narration to fully on-device
sherpa-onnx + Matcha-TTS. Page Shelf only manages local book files that users own or are
authorized to use. Neither the project nor this release contains or distributes book content.

## 主要变化 / Highlights

- 新增未加密、可重排 MOBI7/KF8 导入、目录、元数据与内嵌封面支持；
- 新增 `http://<服务器IP>:8000/reader` 网页阅读器；
- 管理后台入口为 `http://<服务器IP>:8000/admin#books`；
- Android 支持 MOBI 在线与离线阅读、下载和进度同步；
- Android 朗读改为 sherpa-onnx + Matcha-TTS 单女声，中文与英文均在设备本地合成；
- 移除未接入客户端的独立实验性 TTS 服务及其 Docker、CI 和文档配置。

MOBI 仅支持未加密、可重排文件。DRM 文件不会被绕过或导入，Print Replica 固定版式请先通过合法
流程转换为 PDF。

## 下载 / Downloads

- `page-shelf-v1.1.0-arm64.apk`：Android 8.0+，仅支持 `arm64-v8a`；
- `page-shelf-v1.1.0-docker.zip`：Docker Compose 后端部署包；
- `SHA256SUMS.txt`：APK 和部署包的 SHA-256 校验值。

## Docker

镜像支持 `linux/amd64` 和 `linux/arm64`：

```bash
docker pull ghcr.io/samworthington39-commits/page-shelf:v1.1.0
```

更新已有部署：

```bash
docker compose pull
docker compose up -d --force-recreate
```
