# 页架 Page Shelf v1.2.0

**NAS 图书管理器 / NAS Library Manager**

本版本新增 Android 朗读睡眠定时、管理后台单书隐藏/恢复、可配置书架扫描间隔与“古文拆分”章节方式，
并移除了登录会话的定时过期；页架只管理用户自己拥有或有权使用的本地图书文件，本项目及本 Release
不包含或分发任何图书资源。

This release adds an Android narration sleep timer, per-book hide/restore in the admin console,
configurable shelf scan intervals, a dedicated classical-Chinese chapter splitter, and removes
login session expiry. Page Shelf only manages local book files that users own or are authorized to
use. Neither the project nor this release contains or distributes book content.

## 主要变化 / Highlights

- Android 朗读新增睡眠定时：可设置 15/30/45/60 分钟或播放完当前章后自动停止；
- 管理后台支持将单本书从书架中隐藏或恢复（读者端不再显示，管理端仍可见并可一键恢复）；
- 书架扫描间隔支持按分钟、小时、天、周设置；
- 章节拆分新增“古文拆分”方式：识别卷体（卷X/卷之X/卷上中下/上中下卷）、第X回/则/出/品、
  经书篇名+序数（如“学而第一”）、史书纪传表志（如“项羽本纪”）与组诗“其一/其二”等古籍体例；
- 移除登录会话的有效时限：内网部署下会话不再定时过期，仅在修改管理密码后全部失效；
- 移除“隐藏书架”功能，书架只保留可选的四位访问密码；
- 新建书架直接使用所选存储位置的整个目录，点击“创建并扫描”后卡片立即关闭、首次扫描在后台继续；
- 修复升级自旧版数据库后遗留的 `is_hidden` 非空列导致新建书架被误报已存在的问题。

## 下载 / Downloads

- `page-shelf-v1.2.0-arm64.apk`：Android 8.0+，仅支持 `arm64-v8a`；
- `page-shelf-v1.2.0-docker.zip`：Docker Compose 后端部署包；
- `SHA256SUMS.txt`：APK 和部署包的 SHA-256 校验值。

## Docker

镜像支持 `linux/amd64` 和 `linux/arm64`：

```bash
docker pull ghcr.io/samworthington39-commits/page-shelf:v1.2.0
```

更新已有部署：

```bash
docker compose pull
docker compose up -d --force-recreate
```
