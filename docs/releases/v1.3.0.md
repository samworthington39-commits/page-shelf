# 页架 Page Shelf v1.3.0

**NAS 图书管理器 / NAS Library Manager**

本版本更新 Android 阅读与书架界面的 Liquid Glass 视觉，并修复阅读进度同步和登录失效处理中的几个问题。
页架只管理用户自己拥有或有权使用的本地图书文件，本项目及本 Release 不包含或分发任何图书资源。

This release updates the Android reader and shelf UI with Liquid Glass visuals and fixes several
reading-progress sync and session-expiry issues. Page Shelf only manages local book files that users
own or are authorized to use. Neither the project nor this release contains or distributes book content.

## 主要变化 / Highlights

- Android 阅读与书架界面采用 Liquid Glass：悬浮胶囊栏、暖色纸张主题、滚动安全的玻璃卡片、瀑布式连续
  阅读和新的玻璃控件；
- 优化书架长列表滚动与阅读器进入/退出动画，减少滚动时的停顿；
- 修复阅读进度冲突弹窗中“使用本机进度”按钮消失的问题；
- 登录失效后立即清理本地会话并回到服务器设置页重新登录，不再等到下次启动；
- 阅读进度同步遇到 401 时保留本地队列，重新登录后重置退避并立即补传，不再静默丢弃未同步进度；
- 下载任务遇到登录失效时改为等待重新登录后自动重试，而不是把任务标记为失败。

## 下载 / Downloads

- `page-shelf-v1.3.0-arm64.apk`：Android 8.0+，仅支持 `arm64-v8a`；
- `page-shelf-v1.3.0-docker.zip`：Docker Compose 后端部署包；
- `SHA256SUMS.txt`：APK 和部署包的 SHA-256 校验值。

## Docker

镜像支持 `linux/amd64` 和 `linux/arm64`：

```bash
docker pull ghcr.io/samworthington39-commits/page-shelf:v1.3.0
```

更新已有部署：

```bash
docker compose pull
docker compose up -d --force-recreate
```
