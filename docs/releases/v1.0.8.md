# 页架 Page Shelf v1.0.8

**NAS 图书管理器 / NAS Library Manager**

页架用于管理用户自己拥有或有权使用的本地 TXT、EPUB、PDF 文件。本项目及本 Release 不包含、不提供、
不内置，也不分发任何图书资源。

Page Shelf manages local TXT, EPUB, and PDF files that users own or are authorized to use. Neither the project nor
this release contains or distributes any book content.

## 下载 / Downloads

- `page-shelf-v1.0.8-arm64.apk`: Android 8.0+，仅支持 `arm64-v8a`。
- `page-shelf-v1.0.8-docker.zip`: Docker Compose 后端部署包。
- `SHA256SUMS.txt`: APK 和部署包的 SHA-256 校验值。

## Docker

镜像支持 `linux/amd64` 和 `linux/arm64`：

```bash
docker pull ghcr.io/samworthington39-commits/page-shelf:v1.0.8
```

也可以使用滚动更新标签：

```bash
docker pull ghcr.io/samworthington39-commits/page-shelf:latest
```

解压 Docker 部署包后：

```bash
cp .env.example .env
mkdir -p library data
docker compose pull
docker compose up -d
```

管理界面为 `http://<服务器IP>:8000/admin`，默认密码是 `112233`。首次登录必须立即修改密码。
Android App 中填写 `http://<服务器IP>:8000`，不要添加 `/admin` 或 `/api/v1`。

## 主要功能 / Highlights

- NAS 目录授权、书架创建与自动扫描；
- TXT、EPUB、PDF 阅读和离线下载；
- 多设备阅读进度同步；
- 完全离线的中文朗读；
- 默认只读挂载图书目录，数据库和封面独立持久化。
