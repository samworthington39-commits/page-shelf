01 / THREE SURFACES

一份书库，三种阅读姿态

同一个后端把“管理”“阅读”“朗读”拆成各自擅长的界面。书籍原文件保持只读，客户端只拿到完成阅读所需的内容窗口。

API

Docker 后端

FastAPI + SQLite / SQLAlchemy，负责发现挂载、扫描书籍、提取元数据、拆分章节、生成封面与保存统一进度。

  • 只读挂载，原文件不改写
  • 书架 / PIN / 管理后台
  • Range、ETag、流式下载
WEB

PC 网页阅读器

同源提供的免安装阅读入口，TXT、EPUB、MOBI 以章节滚动，PDF 保留浏览器原生固定版式。

  • 目录、搜索、主题与字号
  • 章末自动续接下一章
  • 独立浏览器设备 ID
APP

Android App

Jetpack Compose 的离线阅读端：书架横向切换、整书下载、章节缓存、PDF 渲染，以及不上传正文的端侧 TTS。

  • Room 本地优先进度
  • WorkManager 断网重试
  • sherpa-onnx + Matcha-TTS
02 / BACKEND CORE

后端不是文件索引
而是阅读中间层

它把不同格式的书，整理成网页和 App 都能理解的“书籍—目录—章节—进度”模型。前端不需要知道 EPUB spine、MOBI 锚点或 TXT 标题规则。

把复杂留在服务器里

挂载目录由授权根路径控制；扫描器登记书架和书籍元数据；解析器只读取原始文件，产出可缓存的章节正文。客户端只围绕阅读体验工作。

03 / CHAPTER ENGINE

章节拆分，发生在后端

TXT 的标题不总是规整，古籍、网文与英文书也各有自己的格式。页架为每本书保存独立的拆分策略，先识别、再校验，必要时回退到安全的单章或固定长度。

智能识别，保守回退

识别“第十二章、Chapter IV、序章、卷之二、其一”等常见结构，候选过密或正文过短时自动回退到严格规则。

  • 保留原始标题，另存标准化标题
  • 记录卷号、章号、子序号与上中下顺序
  • 策略变化提升 content version

04 / ONE PROGRESS MODEL

PC 读到哪，手机接着读

网页和 App 使用同一套阅读进度模型：章节、比例、字符偏移、段落索引、PDF 页码、设备 ID 与内容指纹都被记录。同步不是“覆盖”，而是带规则的恢复。

05 / ON-DEVICE NARRATION

手机不仅能看
还可以在本地读给你听

Android App 内置 sherpa-onnx + Matcha-TTS。正文不上传第三方服务，文本先分句，再生成短 WAV，边播边缓存，队列会提前准备后续片段。

端侧合成，离线也成立

端侧生成让朗读和书籍下载一样属于设备能力：没有网络时仍可继续，缓存只保存在 App 私有空间。NarrationService 负责后台播放、队列推进、睡眠定时器与章节切换。

06 / OFFLINE BY DESIGN

网络只是加速器
不是阅读的前提

下载、缓存、同步、朗读被拆成独立任务。在线时拿到新内容，离线时使用本地副本；网络恢复后再把最新进度送回服务器。

01 / DOWNLOAD

整书下载

支持 Range、ETag、断点续传、SHA-256 校验与失败重试。原始 TXT / EPUB / MOBI 可保存为永久离线副本。

02 / CACHE

章节窗口

在线阅读按需拉取当前章节，前后各 5 章预取；临时缓存和永久下载分开，清理不会误删进度。

03 / RETRY

可恢复同步

上传失败时按 bookId 合并队列，只保留最新任务；WorkManager 使用指数退避，最长等待 6 小时。

04 / PDF

固定版式

PDF 不进入章节表，交给 Android PdfRenderer。只缓存当前页前后有限范围，不做 OCR，不改变原页面。

07 / DEPLOYMENT

一个容器，接上你的书库

后端面向 NAS 和家庭服务器设计。Docker Compose 负责 API、数据目录与书库挂载；Android 通过服务器地址连接，网页阅读器由同一服务提供。

三步启动

mkdir page-shelf && cd page-shelf curl -LO deploy/compose.yaml mkdir -p library data docker compose pull docker compose up -d → /admin#books　初始化与扫描 → /reader　　　网页阅读入口 → /health　　　服务健康检查

边界清楚，才敢长期使用

管理 Cookie 与阅读 Bearer 会话隔离；网页密码只存当前标签页，Android 用 Keystore 保存可撤销会话。默认关闭 CORS 和 API 文档，公网部署应置于 HTTPS 反向代理之后。
