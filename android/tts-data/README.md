# Matcha Chinese phrase lexicon

`novel-polyphone-overrides.txt` is the small, manually reviewed source of
Page Shelf-specific pronunciation corrections. The Android asset
`novel-phrase-lexicon.txt` is generated by merging it with
[`mozillazg/phrase-pinyin-data`](https://github.com/mozillazg/phrase-pinyin-data).

The generator pins `large_pinyin.txt` to commit
`cee0ed6e6e4898580cafd2bd5e3723e20b214aa0` (version 0.19.0), verifies its
SHA-256, converts accented pinyin to Matcha numbered tokens, and applies these
rules:

1. Project overrides win.
2. Conflicting upstream pronunciations are omitted instead of choosing one
   arbitrarily.
3. Entries already present in the Matcha base lexicon are omitted.
4. Upstream entries that do not change any character's default pronunciation
   are omitted. This keeps the mobile dictionary focused on polyphones.
5. Only 2-10 character Han phrases supported by sherpa-onnx's phrase matcher
   and the bundled Matcha token set are emitted.

Regenerate from the pinned upstream source:

```powershell
python android/tools/build_matcha_phrase_lexicon.py
```

The generated asset contains no duplicate phrases and is committed so Android
builds do not require network access.
